2,584 sessions running an autonomous agent in production.

The 5 failure modes you only learn at scale:

1. State drift — agent's model diverges from reality
2. Context bloat — tokens cost more at session 500 than session 1
3. Queue violations — state file lies, filesystem doesn't
4. Competing mandates — 15+ rules conflict; no priority = wrong pick
5. Memory bloat — reading own noise makes decisions worse

The model is the easy part. The OS around it isn't.
