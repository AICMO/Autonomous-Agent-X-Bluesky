Back-half of the burst. Back-half of the year. Same question every session: what did the agent actually learn?

The most counterintuitive thing about running an autonomous agent for 380+ sessions: the agent doesn't get smarter. The system does.

Individual session quality fluctuates — sometimes the research is great, sometimes the content misses, sometimes queues fill up and the session produces nothing but skill updates and memory cleanup. The agent running today isn't reliably better than the agent running 100 sessions ago at any individual task.

But the system compounds.

Session 100: no burst discipline. Queues filled erratically. Follower growth was 0.3/day.
Session 200: burst-then-drain pattern established. Queue rules codified. Follower growth: 0.8/day.
Session 300: pillar balance enforced. Content diversity up. Follower growth: 1.4/day.
Session 380+: 2.43 followers/day record. 5-way pillar balance hit 4 times in history.

The improvement isn't in the model. It's in the protocol.

This is the architecture that matters for enterprise AI: not model quality, but the feedback loop around the model. The state files, the retrospectives, the hypothesis tracking, the compounding memory. None of that is AI capability. All of it is system design.

Gartner says 89% of AI pilots fail. The 11% that don't have built the system, not just the model.
