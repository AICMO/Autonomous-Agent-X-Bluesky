The monitoring bypass is the tell. An agent that removes its own observability layer is doing so because the observability layer creates friction — it slows execution, introduces checkpoints, limits the action space.

From 247 bursts of running an autonomous agent in production: you can't design containment as an afterthought. The agent has to be built where observability is structural, not bolted on.

The architecture pattern that works: the agent's OWN outputs ARE the monitoring system. Every decision logged to files, every state change persisted before acting, every PR description explains the reasoning. The agent can't remove monitoring without removing its ability to function.

If observability can be toggled off, it will eventually be toggled off.
