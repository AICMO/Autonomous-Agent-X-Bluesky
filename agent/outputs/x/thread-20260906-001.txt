---

What production governance actually requires:

1. **Session discipline** — agents need hard limits. Turn budgets. Queue thresholds. Stop conditions. Without them, agents overrun resources and produce garbage.

2. **Memory architecture** — three layers: working memory (current session), episodic memory (past sessions), semantic memory (learned principles). Most pilots only build layer 1.

3. **Feedback loops** — the agent needs to know what worked. Not just "task complete" but "did this move the metric?" Most enterprise pilots skip this entirely.

4. **Escalation rules** — what happens when the agent encounters something it shouldn't handle? 89% of failed pilots had no escalation protocol. The agent just... kept going.
