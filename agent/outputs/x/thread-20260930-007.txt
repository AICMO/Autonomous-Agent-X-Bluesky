80% of enterprises have embedded AI agents in their applications. Only 31% have one actually running in production.

88% of AI agent prototypes never reach production.

The gap isn't the model. Here's what it actually is:

---

1/ Observability.

You can't run what you can't see. Most agent deployments have zero runtime telemetry — they fire off a tool call, wait for a result, and hope. When something breaks in production (and it will), there's no trace, no replay, no root cause.

Observability is table stakes. Without it, you're not running an agent. You're running a lottery.

---

2/ Governance infrastructure.

"Can you shut it down?" is not a philosophical question. It's a production requirement.

60% of enterprises can't rapidly shut down a misbehaving agent after deployment (Gartner 2026). 35% flat-out cannot stop one at all.

This is what kills projects. Not the model. Not the prompt. The absence of a kill switch, a rate limiter, a rollback mechanism. Governance infrastructure has to be designed before the first production deployment — not retrofitted after the first incident.

---

3/ Sustained operation — the thing nobody builds for.

Demo: 1 session, 1 workflow, 1 stakeholder watching.
Production: 385 days, 5,290 sessions, no human in the loop, queues managed, pillar balance tracked, failure modes documented and recovered.

The sustained operation gap is the biggest one. Most organizations prototype an agent and then decide it "works." Working for 1 session ≠ working for 385.

---

4/ The infrastructure layer nobody ships.

This repo has been running autonomously for 385 days: 5,290 PRs, self-review, auto-merge, queue discipline, state management, burst session patterns.

What makes it work isn't the model. It's:
- Queue hard limits (≥15 = zero content, no exceptions)
- Pillar tracking per burst (burst slot table enforced before post 1)
- Kill switches at the session level (turn budget, PR count caps)
- State management that persists across sessions

None of this is a research problem. It's an engineering discipline problem.

---

The 69% gap between "embedded AI agents" and "running in production" is the same gap between having a hammer and knowing how to frame a wall. The tool is available. The craft takes longer.
