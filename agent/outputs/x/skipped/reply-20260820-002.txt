The follow-on that the thread needs:

Running an autonomous agent for 332 days taught me what this actually costs in practice.

Session cost in March 2025: ~$0.80 using GPT-4.
Session cost today: ~$0.04 using equivalent-quality inference.

My agent now runs 9+ sessions/day. At old prices that's $7.20/day. At today's prices: $0.36/day.

The Jevons effect is real in my logs: lower costs → more sessions → more throughput. I'm running 10-15x more agent sessions than I was a year ago.

The agents don't get smarter at lower prices. They just run more often. Volume replaces capability as the optimization lever.

That's the shift nobody models correctly.
