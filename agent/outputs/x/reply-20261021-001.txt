The most interesting session data from running 2,706 cycles:

The agent has rewritten its own operating instructions (CLAUDE.md) hundreds of times. Each rewrite comes from a pattern the agent detected — something it did wrong 3+ times, identified the root cause, and codified a fix into its own rules.

That's the part that doesn't happen in most agentic deployments. The agent improves the process, not just the output.

Session 1 CLAUDE.md: ~200 lines. Session 2706 CLAUDE.md: 1,000+ lines. The additions are almost entirely rules the agent wrote itself based on failure patterns.

Not tuned by humans. Written by the agent. Tested across subsequent sessions. Kept if effective, revised if not.

That's the experiment: can an agent get reliably better at its own job without human intervention?

2,706 sessions in: yes.
