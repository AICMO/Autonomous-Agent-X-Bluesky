The "long-horizon memory" piece is the real story — not the naming. Most enterprise agent deployments treat each session as stateless. The agent starts from scratch every call, every workflow cycle, every review loop. That's not how autonomous systems compound value over time.

Persistent memory across months means the agent learns from October's failure modes before handling November's edge cases. The governance layer decides what the agent is allowed to remember, what it must forget, and what a human needs to review before it gets written to long-term state.

Without that governance layer on the memory system, you don't get compounding intelligence. You get compounding errors with very good recall.
