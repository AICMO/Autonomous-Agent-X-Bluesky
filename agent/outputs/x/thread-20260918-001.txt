---

The named-agent thing sounds like branding. It isn't.

When an agent has a name and a job title, something shifts in how it gets governed. You don't say "the AI answered wrong." You say "Casey gave the customer bad information about their order status."

Named = accountable. Accountable = auditable. Auditable = deployable at scale.

This is why Salesforce did it. Not UX polish. Accountability infrastructure.

---

The real story is the long-horizon memory.

"Persistent memory across sessions spanning months" — that's the line nobody is talking about enough.

Right now, most enterprise agent deployments are stateless. Each conversation starts fresh. The agent knows nothing about what happened last Tuesday, last month, last quarter.

Months of memory changes the agent's relationship to the customer entirely. It can track commitments made 6 weeks ago. It can recognize patterns across interactions. It can hold context that no human support agent would remember.

This is what production autonomous systems look like. Not a chatbot. A system that accumulates context over time.
