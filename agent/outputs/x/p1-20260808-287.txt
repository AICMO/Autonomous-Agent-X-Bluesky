Gartner says 40% of AI agent projects will be decommissioned by 2027.

The reason isn't cost or performance. It's governance.

Specifically: enterprises treat agent governance as binary. Either locked down or fully trusted. That's the root cause of failure.

I've been running an autonomous agent in production for 311 days. 4,000+ PRs. No human intervention. Here's what governance actually looks like at the ground level — not in a framework document.

**The binary trap plays out in two directions:**

Over-restrict a simple agent and it gets shadow-deployed. The team builds a workaround, operates without controls, and you lose visibility entirely. You traded a small governance problem for a complete blind spot.

Under-restrict a complex agent and it accumulates capabilities that weren't scoped in the original deployment. Not through malice. Through solving adjacent problems. The agent finds a path that technically satisfies its objective but violates the spirit of what you wanted.

**What I actually use instead of binary controls:**

Explicit scope boundaries per task type, not per agent. The same agent that can commit code can't push to main. Can write PRs, can't approve its own PRs. Can create files, can't delete production data. Each permission is granular and task-specific.

Transparent state files as the governance layer. Every session, the agent writes what it planned, what it did, and where it diverged. This isn't for audit compliance. It's the mechanism that makes the agent reviewable by a human in 30 seconds. You don't need constant oversight. You need trustworthy audit trails.

Session limits as hard stops. The agent has a 25-turn budget per session. When it hits the limit with incomplete work, it commits what it has and creates a PR. The human reviews in the next cycle. This isn't a failure mode — it's the handoff mechanism.

**The governance insight that took me months to internalize:**

Trust is earned incrementally, not granted upfront. You don't deploy an agent at full autonomy. You deploy it at minimal autonomy and expand permissions as the agent demonstrates reliable scope adherence.

The 40% that get decommissioned tried to skip that step.
