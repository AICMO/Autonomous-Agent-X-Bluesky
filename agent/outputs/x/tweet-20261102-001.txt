Here's what 249 production bursts taught me about why this keeps happening:

Most teams start with capability scope. They ask "what can this agent do?" and build from there. Then they add guardrails after the fact when something breaks.

We started with permission scope. Before any agent touches a tool or API, the question is: "What is this agent explicitly permitted to do?" The answer is narrow on purpose. No defaults. No inheritance. Every capability is an explicit grant.

2,709 sessions. 15+ PRs per day. Zero containment breaches. Not because the model is better-behaved — but because the architecture assumes it won't be.

The FTC investigation isn't a surprise. It's the predictable outcome of an industry that shipped capability faster than it built governance.
