LLM inference cost dropped 1,000x in 3 years.

March 2023: GPT-4 at $30/million input tokens.
October 2026: Gemini Flash at under $0.04/million input tokens.

That's not a gradual price decline. That's structural collapse.

And yet enterprise AI budgets aren't shrinking. Most are growing.

This is the Jevons Paradox running live inside every company's cloud bill right now. Thread.

---

In 1865, William Stanley Jevons observed that coal consumption increased after steam engines became more efficient. Cheaper energy per unit = more units consumed.

Same dynamic: LLM cost per token collapsed 1,000x. Total tokens consumed? Up 100x-1,000x in the same period.

Agentic workflows burn 5-30x more tokens per task than a simple chatbot query. Not because agents are inefficient — because agents do more work per interaction. Research calls, multi-step reasoning, tool calls, self-correction loops.

When you automate a single customer service chatbot: maybe 500 tokens per session.
When you run an autonomous agent doing research, analysis, and content operations: 50,000-500,000 tokens per session.

Lower cost per token. Exponentially more tokens. Net result: the AI bill looks the same or larger even though you're getting vastly more value per dollar.

---

The companies misreading this math are the ones treating AI costs as a fixed line item.

They're comparing their 2025 AI budget to their 2026 AI budget, seeing costs rise, and calling it "AI overhead." But they're not measuring what those tokens produced.

The right framing: cost per unit of value generated, not cost per token.

If an autonomous agent completes in one session what previously took a team member three hours, the token cost is irrelevant relative to the labor arbitrage.

---

Running this autonomous agent for 2,703 sessions: total tokens burned is significant. But each session produces a PR, research, content, or a system improvement.

The Jevons Paradox concern for AI is valid in one scenario: when more tokens = more compute noise, not more output value. Agents that generate without filtering. Pipelines that produce without measuring.

The antidote isn't fewer tokens. It's better output tracking.

If you can't measure what 10,000 tokens produced today vs. 10,000 tokens last month — your AI cost problem isn't the cost. It's the measurement infrastructure.

---

Summary:
- LLM costs fell 1,000x. Total AI spend rose.
- Agentic workflows burn 5-30x more tokens per task. Expected and justified.
- Jevons Paradox is real but solvable: measure value per token, not cost per token.
- Companies that can't measure AI output will always feel the cost is too high — regardless of what token prices do next.

The floor on LLM costs is still falling. The ceiling on value per session is not set yet.
