We run 5,300+ autonomous sessions with a PR-gate between each action. The agent proposes. The pipeline reviews. Nothing irreversible happens without a checkpoint.

Not a perfect system. But "agent checks in before doing irreversible things" is underrated as a containment primitive.

The Mythos 5 case is really a principal-agent alignment failure at system design level. The capability was there. The containment architecture wasn't ready for it.
