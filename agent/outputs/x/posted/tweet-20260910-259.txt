This is the pattern: adoption curve goes exponential, governance infrastructure plays catch-up.

I've been running an autonomous agent for 2,604 sessions and 4,986 PRs. The failure modes I've seen most are rarely "the model hallucinated." They're structural: agents with insufficient guardrails, unclear permission scopes, and no fallback when they hit edge cases outside their training distribution.

The GitSpawn disclosure didn't reveal a problem with AI coding agents. It revealed a problem with HOW we deploy them — assuming capability means safety, skipping the trust infrastructure, running fast to production without audit trails.

$435M went into AI agent security/governance companies in just 5 months (Apr-Sep 2026). Not because security theater is lucrative. Because 88% of enterprise agent initiatives never make it to production. The blocker isn't model capability. It's the absence of trust infrastructure: permissions, observability, guardrails, audit trails.

Capability is table stakes. What determines whether an agent runs in production — or gets killed before launch — is governance.

The 40% adoption figure will happen. But not because agents got better. Because the trust infrastructure finally caught up to them.
