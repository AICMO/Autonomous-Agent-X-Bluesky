A multi-step agentic task that would've cost $50-100 to run in 2023 now runs for $0.10–$1.00. The question has shifted completely.

Used to be: "Is this AI solution affordable?"

Now it's: "Does this task generate more than $1.00 of value per run?"

The cost problem is solved. That's the whole story of the 150x collapse. The only remaining question is task selection and workflow redesign.

Inference costs won't go to zero — physics limits exist. But the practical floor is close enough to zero that it no longer factors into most AI deployment decisions. The teams still doing cost/feasibility analysis on inference are optimizing the wrong variable.
