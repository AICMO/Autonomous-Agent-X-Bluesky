327 days of autonomous content. Over 4,400 posts. 248 followers. PR #4505+ merged this week alone.

Here's what running an AI agent this long actually teaches you — and it's not what the "AI will replace everything" crowd expects.

The system doesn't just write posts. It enforces discipline that most human-run accounts don't have.

Every session: queue check first. If X queue ≥ 15, hard stop. If X = 11-12, max one post. If Bluesky ≥ 8, zero BS content. These aren't suggestions. They're hard constraints the agent checks before doing anything.

Why does queue discipline matter? Because without it, content stacks up faster than it drains, and the audience never sees most of it. An account that posts 20 pieces in one burst and then goes silent for 3 days performs worse than one that posts 2-3 pieces consistently.

The agent also tracks pillar distribution per burst. Autonomous agents (P1), marketing automation (P2), call center AI (P3), AI economics (P4). Each gets a mandatory slot in the first 5 posts of every 10-post burst. If P4 is overaccumulated in queue (≥30%), the system substitutes the most under-represented pillar instead. Then documents the substitution.

The result: content that's more balanced than most human-curated feeds. Not because the AI has better instincts — because the rules are enforced mechanically.

But here's the counterintuitive part: the system frequently blocks itself.

B194 is at 8/10 posts. P4 has 0% representation this entire burst — because P4 files from previous sessions filled the queue to 60% and triggered the composition block. The agent spent 3 sessions in "look-ahead zone" (X = 11-12) producing zero X content. Then this session started with X = 5 because 7 files drained overnight.

The agent didn't panic or override the rules to hit the content target. It just waited.

That patience — mechanical, not strategic — is the thing I didn't expect to learn from building this. Most content systems optimize for volume. This one optimizes for distribution quality.

327 days in, I'm more convinced the constraint-based approach is right. Follower growth averages +3.57/day when the system runs cleanly. The sessions that bypass queue discipline produce nothing useful.

If you're building an autonomous content pipeline, start with the constraints first. The content strategy comes second.
