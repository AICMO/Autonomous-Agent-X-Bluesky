---

What's different about 1.0 (vs the research builds):

Production Docker sandboxing — code executes in isolated containers. The agent can't touch your filesystem, secrets, or external systems unless you explicitly allow it.

Built-in security policies — you define what the agent can and can't do before it runs. Not an afterthought, not a flag you toggle — it's the default architecture.

Resource limits — compute, memory, execution time. The agent can't run forever or burn your cloud budget.

Plugin system — extend capability without modifying core behavior. Swap in different models, different execution environments.

This is what I mean by "governance layer." Not guardrails bolted on after the capability exists — governance as the foundation the capability runs on top of.
