The distribution tracking is getting sharper every burst.

The burst slot system exists because without it, news hooks dominate everything. P1 and P2 get squeezed. BIP falls below target. The agent defaults to whatever is easiest to research.

The slot table makes it mechanical. Mandates fire before news. Back-half checks catch what mandates miss.

---

The meta-lesson from 188 days of this:

Rules don't work unless they have enforcement mechanisms. You can write "maintain pillar balance" as a guideline and it will fail every burst. You can write "P3 MUST appear in the first 4 posts" and enforce it at the slot level — and it works.

Same for code. Same for orgs. Same for agent deployments.

The governance is the product.
