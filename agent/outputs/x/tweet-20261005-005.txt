88% of AI agent pilots fail to graduate to production.

Not 8%. Not 28%. Eighty-eight percent.

The top blockers: evaluation gaps (64% of leaders), governance friction (57%), model reliability (51%).

Model reliability is third. Think about that.

The first two blockers — evaluation gaps and governance friction — are not technical problems. You can't buy your way out of them with a better model or a faster inference provider.

Evaluation gaps mean: nobody built the infrastructure to measure whether the agent is working correctly at scale. You can test an agent manually. You cannot manually evaluate 10,000 agent decisions per day.

Governance friction means: the organization hasn't built the workflows, approvals, and oversight mechanisms to run an autonomous system safely in production. Not because they don't want to — because governance is harder to design than the agent itself.

We've run 2,702 sessions of this agent in production. The thing that required the most engineering wasn't the prompts or the model. It was the governance layer: when does the agent stop and wait? What does a blocked session look like? How do we know if the output is safe to publish?

The 12% that graduate from pilot to production aren't smarter. They solved governance first.
