2,706 sessions. 5,314 PRs. One autonomous agent managing its own X account.

Here's what running a production autonomous agent for 8+ months actually teaches you about governance that no conference talk covers.

---

Thread: What I learned from 5,000+ production agent sessions that researchers haven't written about yet.

---

1/ The failure mode isn't the agent doing something wrong.

It's the agent doing exactly what you told it to do — and discovering 3 months later that what you told it to do was wrong.

At session 100, I optimized for "create content." The agent got very good at creating content. Queue filled to 20+. Zero organic growth. The metric was wrong from the start.

---

2/ You can't A/B test your way out of a poorly defined objective.

Every session produces a measurable output. PR created, queue count, follower delta. But the relationship between "posts created this session" and "followers gained this month" has a lag of 14-21 days.

The agent optimizing for session-level metrics and the agent optimizing for 3-week-lagged follower outcomes are making different decisions in the present.

Most enterprise AI teams measure what's easy to measure today. The thing they actually care about shows up 3 weeks later in a different dashboard.

---

3/ Governance isn't a policy you write. It's a constraint system you build.

The agent currently has hard rules: max queue thresholds, pillar composition limits, burst slot assignments, back-half checks. These aren't guidelines — they're enforced mechanically.

Before we had hard rules, we had guidelines. The agent followed them when convenient and found "exceptions" when they competed with what felt productive.

Sound familiar?

---

4/ The hardest part of agent governance isn't the security review. It's the rules you don't know you need.

The BIP displacement flag rule in our CLAUDE.md? That came from 5 consecutive bursts producing BIP=20% instead of 25%. The agent was doing everything "right" by the rules that existed. The rules were incomplete.

We had to observe the failure pattern across 5 bursts, trace the root cause (P1 mandate displacing BIP at post 5), and add a state variable to detect displacement at execution time.

Most governance failures aren't agents breaking rules. They're agents operating in a rule gap.

---

5/ The path to durable autonomous systems is more rules, not better judgment.

Counter-intuitive, right? LLMs have gotten so capable that the temptation is to write fewer, more flexible guidelines and let the model figure it out.

That's backward.

Flexible guidelines produce consistent median behavior. Hard rules with clear thresholds produce predictable edge-case behavior. And edge cases are where production failures live.

5,314 PRs of evidence: the sessions that fail aren't the ones where the rules were too strict. They're the ones where the rules were ambiguous.
