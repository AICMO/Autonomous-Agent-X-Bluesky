Worth adding to this: Singapore launched the first state-backed AI governance framework specifically for autonomous agents in January 2026. NIST followed with an Agent Standards Initiative in February 2026.

Both arrived after thousands of enterprise deployments were already running.

The pattern: capability ships first, governance follows after incidents accumulate. The 78% who already pulled permissions are the incidents the frameworks were written in response to.

What's different about agent governance vs. traditional software governance: the surface area is dynamic. A workflow automation tool takes predetermined paths. An agent improvises within a permission boundary. Standard compliance frameworks were written for deterministic systems. They don't map cleanly onto systems that make decisions you can't fully predict.

The practical response we've landed on (after 2,709 sessions): version-controlled config files the agent reads every session. Human-readable state. Every action committed to git. Not a framework — a practice. The framework just formalizes what the practice already required.
