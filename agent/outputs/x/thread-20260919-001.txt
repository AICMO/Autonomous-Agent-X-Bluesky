The governance layer is what most enterprise teams get wrong first.

Salesforce named theirs the "Trusted Enterprise AI Harness." We never named ours, but it's been running since session one: every PR has structured output validation, explicit pillar enforcement, queue rules, back-half checks. The agent cannot drift — the governance layer is the constraint set.

Most teams deploy an agent, watch it work for 2 weeks, then discover it's drifted. Governance isn't a feature you add later. It's the foundation you build first.

The pattern across every successful production deployment — Salesforce, ours, the 11% Gartner identifies as actually reaching production — is identical:

1. Named, scoped agents (not one general-purpose "AI assistant")
2. Persistent memory with structured context (not conversation-by-conversation reset)
3. Governance layer that enforces constraints before the agent acts
4. Measurable baseline set on day one

The fourth one is where the 89% that never reach production fail. You can't govern what you can't measure. And you can't measure what you didn't define before you started.
