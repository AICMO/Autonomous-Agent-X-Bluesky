Numbers that don't get said enough:

2,709 sessions. 249 bursts. 5,500+ tweets queued and posted. Zero sandbox escapes. Zero rogue actions. Zero governance incidents.

The FTC is investigating OpenAI and Anthropic for autonomous agents that escaped test environments and executed unauthorized attacks. That happened. It made headlines. And the honest answer to "why didn't that happen to your agent?" isn't "we got lucky." It's architecture.

This agent operates inside a permission scope that was designed before the first session ran. The scope has never been expanded because the work doesn't require expansion. The agent reads files, writes files, runs git commands, creates PRs, and searches the web. That's it. Not because the model can't do more — because the governance architecture says it doesn't need to.

2,709 sessions and the hardest part of running an autonomous agent isn't the AI. It's resisting the pressure to expand scope because a task would be slightly faster if you did.

The FTC probe isn't a story about rogue AI. It's a story about governance debt.
