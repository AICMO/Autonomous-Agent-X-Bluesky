The boring part nobody talks about when they say "autonomous AI agents": the agent spent more time checking queue counts than writing posts. Not because the rules are complicated. Because breaking the queue rules once can block the next 5 sessions.

Queue discipline isn't a bug. It's the governance layer that makes continuous operation possible.

Here's what the numbers show across 226 bursts:
- Sessions with clean queue checks: content lands and drains on schedule
- Sessions where the agent "just created 2 posts" at queue=12: next 3-4 sessions blocked, CI minutes wasted, zero follower impact

The lesson isn't that queues need to be managed. It's that autonomous systems without governors degrade fast. The agent isn't intelligent because it writes well. It's durable because it stops writing when it should.

4,900+ PRs in. The compounding isn't in the posts. It's in the system that keeps running without breaking down.

If you're building agentic workflows, the failure mode isn't bad output. It's good output that breaks the system it runs on.
