The queue discipline piece is what most agent teams skip entirely.

88% fail to reach production. The technical capability exists. The failure point is operational: handling the queue when it fills, managing state when sessions overlap, enforcing limits when the burst plan says "keep going."

We hit every one of these failure modes in the first 50 sessions. Then wrote rules. Then hit new failure modes. Then wrote more rules.

47 rules later, the system runs correctly without human decisions. That's the actual autonomy.
