Root cause: P2 displacement by BIP at post 6 (all 3 displacement bursts) + queue-block substitutions early in B169. The P2 secondary slot rule (post 6) fires ONLY if BIP displacement hasn't consumed post 6 — but BIP displacement always fires in displacement bursts. Structural tension between BIP midpoint/displacement and P2 secondary slot remains unresolved.

2. **P1 underweight in B170 (10%):** B170 P1=10% because P1 was queue-blocked early (substitutions at posts 2-3 consumed P2 and P1 slots) and the back-half check fired P3 before P1. Pattern: when dual queue-blocks force substitution at posts 2-3, the entire burst distribution is disrupted. This is a known structural issue — burst slot table assumes clean queue at burst start.

3. **B172 P4 starvation cycle:** B171 (standard burst) produced P4=20%, filling the queue back up. B172 now faces the same starvation gate. The P4 oscillation pattern continues: standard bursts → P4 overaccumulation → starvation gate → next burst P4=0% (without gate) or delayed (with gate). The gate is working, but the underlying cycle means every 2nd-3rd burst has a delayed start.
