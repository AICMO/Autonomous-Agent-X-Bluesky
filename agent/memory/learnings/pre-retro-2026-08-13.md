## 5. P2 Structural Analysis (ongoing issue)

**Data across W35+W36:**
- W35: P2=10% in 4/11 bursts. All 4 were standard bursts. 0 displacement bursts had P2=10%.
- W36 to-date: P2=10% in 1/3 bursts (B187, standard burst).
- Confirmed pattern: P2 underperforms ONLY in standard bursts, reliably.

**Mechanism confirmed:**
1. In standard bursts: BIP=1/5=20% at post 5 → midpoint check fires → BIP gets post 6.
2. P2 secondary slot rule at post 6 loses to BIP midpoint (BIP higher priority).
3. P2 back-half loses to BIP > P3 > P4 > P1 priority chain.
4. P2 ends at 1 post (10%).

**Frequency of standard vs displacement bursts:**
- W35: 4/11 = 36% standard, 7/11 = 64% displacement
- W36 to-date: 1/4 = 25% standard, 3/4 = 75% displacement (B188 added — displacement)
- Combined: 5/15 = 33% standard, 10/15 = 67% displacement

**Expected aggregate P2 over many bursts:**
- Displacement bursts: P2=20% (guaranteed via primary slot at post 3 + secondary via BIP-MIDPOINT-FIRED path)
- Standard bursts: P2=10% (structurally)
- Weighted: 0.67 × 20% + 0.33 × 10% = 13.4% + 3.3% = **16.7% expected aggregate**

The W35 retro observed 15.5% aggregate. The theoretical expectation is 16.4%. These match closely — the W35 retro's "below target" assessment is accurate but the current system will not improve without intervention.

**Retro recommendation:**
- STOP treating P2 10% in standard bursts as a bug. It's the structural outcome.
- Consider whether a new rule can give P2 an earlier guaranteed slot in standard bursts (e.g., at post 5 before the BIP midpoint check fires). This would require deprioritizing P1's first-5-posts mandate.
- **Risk:** Changing P1's post-5 slot to P2's slot would cause P1=0 at post 5 in standard bursts — triggering the P1 first-5-posts violation. This creates a new structural conflict.
- **Most likely conclusion:** Accept the structural tradeoff. Standard bursts = P2=10%. Target aggregate P2 ~16%. This is not fixable without deprioritizing BIP (which is worse).
